Week 1 – Building the Basic Chat App UI

In the first week, I focused on creating the overall structure and design of the chat application using HTML and CSS. The goal was to understand how different sections of a chat application are organized and displayed before adding any functionality.

I created the main layout consisting of:

A sidebar to display the list of contacts.
A chat window where conversations would appear.
A message input area containing a text field and a send button.

Using HTML, I structured the different sections of the application and organized them into separate containers. Through CSS, I worked on the visual appearance of the app by adjusting:

Layout and positioning of elements
Spacing and alignment
Fonts and text styling
Borders, sizes, and overall responsiveness

During this process, I became familiar with important CSS concepts such as:

Flexbox for arranging elements
Margins and padding
Width and height management
Positioning
Basic responsive design techniques

At the end of Week 1, the application looked like a chat application with separate sections for contacts, messages, and message input, but it was completely static. No JavaScript functionality such as selecting contacts or sending messages had been implemented yet. The focus was purely on designing and structuring the user interface.
