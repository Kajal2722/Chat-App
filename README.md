Chat Application Project Overview

Over the past four weeks, I have been developing a chat application while learning various web development technologies and concepts.

I started by creating the basic user interface of the application using HTML and CSS. I designed a layout consisting of a sidebar for contacts, a chat window for conversations, and a message input area. During this stage, I learned how to structure webpages using HTML and style them using CSS concepts such as Flexbox, spacing, alignment, responsiveness, and positioning.

After building the static interface, I introduced JavaScript to make the application interactive. I implemented features such as selecting contacts from the sidebar, displaying the selected contact in the chat area, sending messages, dynamically creating message bubbles, adding timestamps to messages, and automatically scrolling to the latest message. This helped me understand DOM manipulation, event listeners, dynamic element creation, and handling user interactions.

Next, I began learning React and explored how modern web applications are built using reusable components. I converted different parts of the chat application into separate React components such as Sidebar, ChatWindow, MessageBubble, and MessageInput. Through this process, I gained experience with JSX, props, component structure, state management using useState, event handling, and organizing a React project into reusable modules.

Most recently, I integrated Firebase services into the application. I learned how to set up and configure a Firebase project, connect it with a React application, and implement user authentication. I worked on features such as user registration, login, Google Sign-In, and logout functionality. Alongside authentication, I also explored Cloud Firestore and learned how data can be stored and managed in a cloud database using collections and documents.

Overall, this project has helped me progress from building a simple static webpage to developing a more interactive React application with authentication and database integration. Along the way, I have gained practical experience with HTML, CSS, JavaScript, React, Firebase Authentication, and Firestore while understanding how these technologies work together to build modern web applications.
