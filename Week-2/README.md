Week 2 – Adding Interactivity with JavaScript

In the second week, I introduced JavaScript to make the chat application interactive. After creating a static interface in Week 1, I focused on implementing the basic functionality expected from a chat application.

I worked on features such as:

Displaying a list of contacts dynamically.

Selecting a contact from the sidebar.

Updating the chat window based on the selected contact.

Sending messages through the input field.

Displaying newly sent messages in the conversation area.

Through this process, I learned important JavaScript concepts such as:

DOM manipulation

Event handling

Functions

Arrays and objects

Conditional statements

Updating webpage content dynamically

By the end of the week, the application was no longer static. Users could interact with the interface, select contacts, and send messages, creating a basic chat-like experience.
