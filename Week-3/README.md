Week 3 – Learning React and Component-Based Development

In the third week, I started learning React and explored how modern web applications are built using reusable components. I recreated parts of the chat application using React to understand its development workflow and advantages over traditional JavaScript.

I learned and implemented concepts such as:

Creating React projects

Functional components

JSX syntax

Props

State management using useState

Event handling in React

Component hierarchy and data flow

To make the application modular, I divided it into separate components, including:

Sidebar

Chat Window

Message Bubble

Message Input

This helped me understand how large applications can be broken down into smaller reusable pieces. I also gained experience with React project structure, imports and exports, rendering components, and managing state within components.
