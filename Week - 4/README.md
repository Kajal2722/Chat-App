Week 4 – Firebase Authentication and Firestore Integration

In the fourth week, I explored Firebase and learned how backend services can be integrated into a React application without building a custom server.

I began by setting up a Firebase project and connecting it to my React application. I then implemented user authentication features, including:

User registration using email and password

User login

Google Sign-In authentication

Logout functionality

While implementing authentication, I learned about:

Firebase configuration

Authentication providers

User sessions

Authentication state management

Error handling during login and signup

In addition, I explored Cloud Firestore, Firebase’s NoSQL database service. I learned how data can be stored, retrieved, and managed in Firestore and gained a basic understanding of:

Collections and documents

Reading and writing data

Organizing application data
Connecting frontend applications to cloud databases

By the end of the week, I had successfully integrated Firebase services into the chat application and gained practical experience with user authentication and cloud-based data storage.
